# Contributing to OAGS

Thank you for your interest in the Open Agent Governance Specification.

## How to Contribute

### Reporting Issues

- Search existing issues before creating a new one.
- Use the `[OAGS-Spec]` prefix in issue titles.
- Clearly describe the section, proposed change, and rationale.

### Pull Requests

1. Fork the repository and create a feature branch.
2. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`).
3. Sign off your commits with `git commit -s` (DCO).
4. Keep PRs focused — one logical change per PR.
5. Reference any related issues.

### Spec Change Process

- **Editorial fixes** (typos, formatting): submit a PR directly.
- **Substantive changes** (new sections, behavioral changes): open an issue for discussion first.
- All changes to `specs/oags-v0.1.md` require at least one maintainer review.

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md).
Report unacceptable behavior to conduct@sekuire.com.
